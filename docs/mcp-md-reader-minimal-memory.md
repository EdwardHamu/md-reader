## 1. 确认的范围与实现

用户选择“极简低内存”：单文档阅读，而非保留多标签的均衡版本。

**保留**：打开文件、拖放、系统文件关联入口、标题目录与锚点、相对 Markdown 链接、文内查找、本地/网络图片、表格/只读任务列表/脚注、基础高亮、阅读界面明暗主题与字号、单实例和窗口位置恢复。

**移除**：编辑和文档写入、所有导出/打印/PDF 预览、多标签、最近文档与会话恢复、文件树、递归扫描/监听、跨文件搜索、KaTeX/Mermaid、emoji 短码、更新检查、系统字体枚举、Mica/额外窗口材质、复杂设置及国际化设置界面。当前界面中文，原有用户文件/设置不主动删除。

公式不计算，Mermaid 作为代码阅读，front matter 按转义文本显示。MDX 不执行 JSX。裸 URL 不额外扫描识别，显式 Markdown 链接与 `<https://…>` 自动链接语法保留。

### 关键实现

- `src/App.vue`：单文档外壳，挂载净化后的 DOM，不再用响应式源文/HTML 历史缓存；字号和主题变化不重新解析。
- `src/reader/latest.ts`：最多一项读取在途，等待位置只存最新请求；旧响应、取消后响应和组件卸载后响应不再渲染。
- `src/reader/markdown.ts`：首篇文档才加载解析模块；highlight.js 核心加 8 类语言，不做语言自动检测；目录从已净化的 DOM 提取，不重复解析 Markdown。
- `src/reader/document.ts` / `paths.ts`：保留 DOMPurify，限制主动内容与链接协议；本地图片转 asset URL，懒加载/异步解码；Windows 盘符、UNC、Unicode 和相对路径经过测试。
- `src/reader/find.ts`：原生 CSS Highlights + Range，不插入包裹节点；150 ms 防抖，最多 1000 个匹配；关闭/切换时清理 Range、注册表和计时器。
- `src-tauri/src/reader.rs`：有界 UTF-8 只读加载；先查大小，再用 `take(MAX+1)` 防止读取过程中增长的文件绕过限制。
- `src-tauri/src/lib.rs`：只保留读取、初始打开/单实例事件；macOS 待开文件仅存最新路径。窗口显式可见，避免删除旧初始化流程后出现隐藏窗口。
- 删除不再使用的组件、composable、导出后端；减少 JS/Rust 直接依赖和前端文件写入/导出权限，加入 CSP。文件选择器仍会间接依赖 Tauri 的 fs 插件，未宣称整个依赖图完全不含该 crate。

## 2. 资源边界

| 项目 | 限制/行为 |
| --- | --- |
| 源文件 | UTF-8，最大 8 MiB；超限报错，不静默截断 |
| 解析 | 最多 60000 行，解析过程中累计最多 60000 个语法节点 |
| HTML | 最大 12 Mi 字符；创建 DOM 前最多 60000 个 HTML 标记，含闭合标记 |
| 显示 DOM | 最多 60000 个元素/文本节点；最多 3000 个标题 |
| 单段代码高亮 | 最多 20000 字符，超出则完整显示纯文本 |
| 查找 | 前 1000 个命中，256 字符查询上限；匹配不跨文本节点 |
| 读取队列 | 一项在途 + 最新一个待读路径 |

语法节点预算在解析期间执行，HTML 标记计数在创建净化 DOM 之前执行，而不只是分配完成后的检查。异常后恢复数组方法和下一次解析的预算已有回归测试。

这些是资源防护边界，不是应用 RAM 的硬上限。图片懒加载也**不是**图片解码内存定额；巨幅图片、滚动加载后的图片、字体/布局及 WebView2 自身仍可能占用较多内存。关闭文档释放引用，不承诺操作系统立即回收工作集。

## 4. 浏览器堆实测（不是原生进程内存）

环境：Windows，Node 24.12.0、pnpm 11.21.0、Cargo 1.95.0、Microsoft Edge **153.0.4234.32**，无头模式，默认 1280×720 视口。两版均使用生产构建、模拟 Tauri IPC、干净浏览器上下文和各自默认排版。

场景：空白页；一篇含一个标题和 2000 个相同段落的文档，段落含粗体、行内代码、显式链接。每个场景每版独立运行 3 次，确认页面无 JS 异常且段落数量一致，执行 `HeapProfiler.collectGarbage` 后读取 `Runtime.getHeapUsage` / `Memory.getDOMCounters`，下表取中位数。

| 指标 | 原版 | 极简版 | 变化 |
| --- | ---: | ---: | ---: |
| 空白页 V8 usedSize | 8.77 MiB | 1.61 MiB | -81.6% |
| 单文档 V8 usedSize | 9.25 MiB | 3.09 MiB | -66.6% |
| 单文档 embedderHeapUsedSize | 15.34 MiB | 18.08 MiB | +17.8% |
| 单文档 backingStorageSize | 2.69 MiB | 0.29 MiB | -89.1% |

单文档 CDP DOM 计数：24,166 → 26,067；JS 事件监听计数：42 → 23。

**结果必须分项理解**：V8 已用堆显著下降，但该样本的嵌入器/DOM 相关堆反而上升约 17.8%。默认排版与 DOM 构建方式也不同，因此不能据此声称“所有内存都下降”，不能简单相加各 CDP 字段，更不能把 66.6% 的 JS 堆下降当作软件总内存下降。

未测量发布版 Tauri 主进程、WebView2 多进程 Private Bytes/Working Set 总和，也未测量长时间阅读、多图/巨图场景。此轮证据支持“静态加载负担和 V8 堆降低、缓存/队列/查找受限”，不是原生整机 RAM 降幅保证。
