# 大文件 Markdown 虚拟阅读

## 打开文件时的选择

| UTF-8 文件大小 | 阅读方式 | 编辑 |
| --- | --- | --- |
| 不超过 8 MiB | 常规 Markdown 排版；超出排版预算时显示原文 | 支持 |
| 超过 8 MiB、不超过 24 MiB | 分段读取，默认尝试 Markdown 排版和虚拟滚动 | 不支持 |
| 超过 24 MiB | 分段读取，使用纯文本虚拟滚动 | 不支持 |

如果大小或排版预算超限，正文上方会标明回退原因。原文不截断，两种视图都可用 Ctrl+F 查找全文。读取失败或文件在读取中被修改则报错，不伪装成回退。

## 渲染与资源边界

- 沿用现有 Tauri 读取协议，每次最多读取 1 MiB 的 UTF-8 数据。对允许排版的文件，将分段按顺序拼接并进行一次文档级解析，避免跨段代码围栏、引用链接、重复标题或脚注被拆坏。此路径不是流式 Markdown 解析。
- HTML 按块净化和切片。阅读区只挂载可视区和缓冲区的块；未挂载内容保留块数据而非 DOM。目录跳转、链接和渲染文字查找仍可跳至未挂载的块。
- 大文件渲染上限：24 MiB 文件、40 万行、40 万语法节点、40 万 HTML 标记、32 Mi 字符 HTML 和 32 Mi 字符序列化块（分别记账）、6 万块。单批净化 DOM 和目录仍受原有上限保护。它们是输入和结构预算，不是进程内存承诺。
- 原文与排版使用不同的分块坐标。新版记录视图类型，只有匹配的视图才恢复保存位置。升级前的大文件原文位置不应用到新排版，首次切换到排版从头开始。
